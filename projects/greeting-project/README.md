# Interactive Greeting Project

## About This Project
This is my first project stored in my Data Science GitHub portfolio.

## What It Does
This Python program asks the user for their name and a data topic they are learning. It then displays a personalized greeting based on the time of day, in both English and Chinese.

## Tools Used
- Python
- GitHub
- Markdown

## What I Learned
I learned how to create a folder in GitHub by typing a path in the filename box, how to write a project README in Markdown, and how each commit saves a snapshot I can compare later.

## Future Improvements
If I continued working on this project, I would add input checking so empty names are rejected, and I would save greetings to a small text file.
